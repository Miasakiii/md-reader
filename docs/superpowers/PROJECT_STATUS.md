## 已完成能力与证据

### 五格式、TeX/LOG 与切换安全

- `shared/document-types.json` 是 `.md`、`.markdown`、`.txt`、`.tex`、`.log` 的运行时能力清单。
- `src/js/file-types.js` 和 `src-tauri/src/file_types.rs` 分别严格消费同一策略。
- `.tex` 以可编辑纯文本打开；`.log` 是可搜索的只读一次性快照，达到或超过 10 MiB 时读取前确认。
- 原生读取不跟随最终符号链接；保存使用同目录临时文件和原子替换。
- 现有打开入口统一经过大型日志确认、未保存修改保护、读取和一次性界面提交。
- `tauri-plugin-fs` 和全部 `fs:*` capability 已移除；系统文件关联仍只注册 `.md`、`.markdown`、`.txt`。

LOG/TeX 核心功能已完成；其唯一遗留的独立安装环境验收不再重复计算，统一由 v1.2.0 封板计划追踪。

### 原生窗口栏主题

- `src/js/window-theme.js` 将浅色/护眼映射为原生浅色窗口栏，将深色映射为原生深色窗口栏。
- 快速切换会串行执行并合并到最新主题；单次原生调用或错误报告失败不会阻塞后续同步。
- `src/js/app.js` 已在主题切换和 Tauri 初始化完成后同步原生窗口主题。
- `src-tauri/capabilities/default.json` 只增加所需的 `core:window:allow-set-theme` 权限。
- `tests/window-theme.test.js` 覆盖主题映射、浏览器降级、快速切换和失败恢复。

## 封板后的实施路线

### 1. 外链最小路由

**实现完成度：0%。** 只处理 `http`、`https`、`mailto` 和未知协议拦截：原生端通过最小 scope 的系统 opener 打开允许协议，浏览器预览使用安全的新窗口降级；不得顺带实现本地文档链接、返回栈或滚动恢复。

### 2. 持久化文件库 MVP

**实施约束已核实；实现完成度：0%。**

当前应用仍使用 `recent.json`，最多保存 20 条，并在后端读取、解码成功后立即登记。以下交付物尚不存在：

- `src-tauri/src/storage.rs`、`src-tauri/src/library.rs` 与 `library.json`。
- `get_library_files`、`register_library_file`、`remove_library_file`、`document_path_status` 四个 MVP 命令。
- `recent.json` 的一次性迁移、严格 JSON、同目录 tmp/bak 恢复、进程内存储锁和仅调试构建可用的隔离配置目录。
- `tauri-plugin-single-instance`、相对 CLI 路径绝对化及通过现有 `OpenFileQueue` 的第二实例转发。
- `src/js/file-library.js`、文件目录侧栏、与文章 TOC 互斥的单一侧栏状态、移出记录、响应式样式及相应测试。
- 在文档成功应用到界面后登记文件库；登记失败只提示，不回滚已经打开的文档。

MVP 明确不包含磁盘删除、`trash_library_file`、`navigation.js` 或返回按钮。验收必须覆盖五种格式、MRU、重启持久化、移出记录、缺失路径、三主题和 600px 最小窗口。

### 3. 安全回收站

**依赖文件库 MVP；实现完成度：0%。** 新计划必须单独覆盖 `trash_library_file`、仅允许已登记且策略支持的普通文件、从 no-follow 文件句柄构建的二次身份复核、系统回收站事务日志、失败/崩溃恢复和阅读进度清理。测试只能操作本轮创建的临时夹具，不得移动或删除用户文件。

### 4. 真实透明圆角图标（可并行）

**基线核查已完成；实现完成度：0%。**

- `src-tauri/icons/app-icon-source.png` 是 1024×1024 RGBA 规范源图，但四角 alpha 仍为 255。
- 当前 32/64/128/256 PNG 派生图同样全域不透明。
- `assets/app-icon.png` 与规范源图逐字节相同，重复文件尚未删除。
- 本地 Tauri CLI 2.11.4 可把候选图标先生成到临时输出目录。

实施时只做确定性的 alpha 蒙版：RGB 全部保持不变，圆角半径为画布宽度的 20%，只允许几何边缘及蒙版外 alpha 变化。候选逐像素验证和临时派生图检查全部通过后，才允许替换规范源图、重新生成正式图标集并删除重复文件。任何门槛失败都在覆盖正式资源前停止。
