# 文件目录、链接导航、图标与项目清理设计

**日期：** 2026-07-16
**状态：** 交互设计已确认，等待书面规格复核

## 背景

MD Reader 当前只在欢迎页展示最近 8 个文件，阅读时没有文件侧栏。最近文件由 Rust 后端写入 `recent.json`，最多保存 20 条。Markdown 正文目前没有统一的链接路由：正文点击委托只处理“复制代码”，因此网页链接会按 WebView 默认行为在应用内导航。

当前应用图标虽然画面内有圆角卡片，但源图和派生 PNG 的四角像素仍完全不透明，系统显示时仍可能呈现方形底。项目还存在一个未引用的单行 CSS 文件、未使用的 Rust 结构、JavaScript 冗余变量、重复图标源文件及 README 过时目录说明。

## 目标

1. 新增阅读时可展开的持久化文件目录侧栏。
2. 支持从目录中移除记录，或经二次确认将原文件移入系统回收站。
3. 将网页链接交给系统默认程序打开，并为文档内锚点和本地文档链接提供明确、可返回的应用内行为。
4. 为应用图标添加真实透明圆角，同时保持现有图案、颜色和阴影不变。
5. 拆分新增职责并删除已经证实无用的代码与文件，不进行猜测式大清理。

## 非目标

- 不扫描用户选择的真实文件夹，也不实现递归文件树、文件监控或目录授权管理。
- 不支持从侧栏删除任意类型文件；只处理已登记的 `.md`、`.markdown` 和 `.txt` 普通文件。
- 不改变 Markdown 引擎、主题体系、编辑器布局或发布流程。
- 不删除 Tauri 打包所需图标、示例文档或现有发布脚本。
- 不包含提交、推送或发布版本的工作。

## 总体架构

采用“轻量文件库”而非真实文件系统树：成功打开过的受支持文件自动进入持久化列表，列表顺序即最近使用顺序。Rust 后端负责存储、路径校验与回收站操作；前端负责侧栏、菜单、链接路由和导航历史。

新增模块边界：

- `src/js/file-library.js`：文件目录视图、当前项选择、右键菜单和关闭行为。
- `src/js/navigation.js`：链接分类、本地路径解析和文件导航历史。
- `src/js/app.js`：保留应用状态与模块协调，不再承载新增功能的全部实现。
- `src-tauri/src/library.rs`：文件库持久化、登记/移除、路径安全校验和回收站调用。
- `src-tauri/src/main.rs`：保留文件读写、阅读进度、应用生命周期和命令注册。

文件侧栏和现有文章目录侧栏共用左侧区域并互斥显示，避免同时挤压阅读区。

## 文件目录体验

### 打开与展示

- 工具栏新增“文件目录”按钮，阅读、编辑和欢迎状态均可展开。
- 侧栏列出全部已登记文件；最近成功打开的文件排在最前。
- 每项显示文件名和完整路径，当前打开文件高亮。
- 单击条目使用现有阅读器打开文件。
- 欢迎页继续展示文件库前 8 项，避免移除现有快速入口。
- 打开文件目录时自动关闭文章目录；打开文章目录时自动关闭文件目录。

### 右键菜单

在文件项上右键，或聚焦条目后按菜单键/`Shift+F10`，显示自定义菜单：

1. **移出文件目录**：只删除文件库记录，不修改磁盘文件，也不清除其阅读进度。若该文件当前已打开，内容保持打开，但侧栏不再显示它。
2. **移到回收站…**：先显示系统确认框。确认文字包含文件名，并明确文件可从系统回收站恢复；若当前文档有未保存修改，额外提示这些修改会丢失。

回收站操作成功后才移除文件库记录并清除该文件的阅读进度。若被移除的是当前文件，应用清空编辑状态并回到欢迎页。操作失败时保留文件库记录和当前页面，并显示具体错误。

菜单在选择操作、点击菜单外、窗口失焦、滚动侧栏或按 `Esc` 时关闭。菜单位置被限制在可视窗口内，不允许溢出底部或右侧。

### 持久化与迁移

- 新文件库使用 `library.json` 保存路径字符串数组，不设置 20 条上限。
- 首次升级且 `library.json` 不存在时，从现有 `recent.json` 导入已有条目；旧文件保留用于版本回退。
- 只有文件读取并解码成功后才登记路径。
- Windows 下去重时忽略路径大小写；其他平台保留平台原有路径语义。
- 读取失败后若确认文件已不存在，前端提示并移除失效记录；权限、编码或临时设备错误不会自动删除记录。

## 链接与返回行为

正文阅读区和编辑预览区共用同一链接路由：

### 网页与系统链接

- `http:`、`https:` 和 `mailto:` 由 Tauri 的系统打开能力交给默认浏览器或邮件程序。
- 点击时阻止 WebView 默认导航，因此 MD Reader 的当前文件、滚动位置和编辑状态保持不变。
- 浏览器预览模式使用带 `noopener,noreferrer` 的新窗口作为降级行为。
- 其他协议默认拦截并显示提示，不传给系统执行。

### 文档内锚点

- `#heading` 链接只在当前阅读容器内滚动到对应标题。
- 不改变 WebView 页面地址，也不创建文件导航历史。
- 找不到目标时不离开当前页面，并显示简短提示。

### 本地文档链接

- 相对或绝对的 `.md`、`.markdown`、`.txt` 链接在 MD Reader 内打开。
- 相对路径以当前文件所在目录为基准解析，并支持链接尾部的标题片段。
- 打开前记录当前文件路径和滚动位置；成功打开后将记录压入导航栈。
- 导航栈非空时，工具栏显示紧凑的“返回”按钮。返回会重新打开上一文件并恢复原滚动位置，且不会再次向栈内压入相同记录。
- 手动从文件目录、打开对话框或拖拽切换文件时清空链接导航栈，避免“返回”含义不明确。
- 解析结果不是受支持文件类型、目标不存在或读取失败时，保持当前文件不变并显示错误。

## 后端安全边界

回收站命令必须同时满足以下条件：

1. 请求路径与文件库中的已登记条目匹配。
2. 路径当前存在且是普通文件。
3. 扩展名为 `.md`、`.markdown` 或 `.txt`，比较时忽略大小写。
4. 前端已经取得用户确认；后端仍独立执行路径校验，不能依赖前端正确性。

实际删除使用跨平台系统回收站能力，不调用永久删除 API。只有回收站调用成功后才更新 `library.json` 和 `progress.json`。外部链接能力仅放行 `http`、`https` 与 `mailto`，并维持现有 CSP 和 DOMPurify 过滤。

## 图标处理

- 以 `src-tauri/icons/app-icon-source.png` 作为唯一源图。
- 在 1024×1024 源图上应用半径为画布宽度 20% 的圆角矩形透明蒙版；蒙版外 alpha 为 0，蒙版内原始像素保持不变。
- 重新生成 Tauri 桌面打包使用的 PNG、ICO 和 ICNS 派生图标，并检查小尺寸边缘无白色方角或明显锯齿。
- 删除重复的 `assets/app-icon.png`；若 `assets/` 因此为空，则一并移除该目录。
- 保留 Tauri 工具生成且仍可能用于目标平台的派生图标目录。

## 项目清理

本次清理只包含有直接证据的项目：

- 删除未被 HTML 或 CSS 导入的单行 `src/css/scrollbar.css`。
- 删除未被管理或引用的 Rust `AppState` 结构。
- 删除 `saveProgress` 中未使用且始终指向同一元素的 `container` 变量。
- 删除重复图标源文件，并在 README 中标注唯一源图位置。
- 修正 README 项目树中不存在的 `build-portable.sh`、`build-portable.bat`，补充文件目录、链接和回收站行为。
- 通过编译器、测试和引用搜索确认其他候选项；没有明确证据的代码和文件不删除。
- 保留用户当前未提交的 `.gitignore` 修改，不纳入规格提交或后续功能提交，除非用户另行要求。

## 错误处理

- 文件库读取失败：保留当前文档，侧栏显示可重试的错误状态。
- 移出目录写入失败：恢复条目并显示错误，不做乐观成功提示。
- 回收站取消：不改变任何状态。
- 回收站失败：保留条目、当前文档和阅读进度，显示系统返回的原因。
- 系统浏览器打开失败：当前文档不变并显示链接打开失败提示。
- 本地链接打开失败：不压入导航栈，当前文档和滚动位置保持不变。
- 返回目标已丢失：移除该条无效历史，提示用户，并继续允许返回更早记录。

## 测试策略

所有行为变更遵循红—绿—重构：先写能复现缺失行为或错误行为的测试，确认预期失败，再实现最小修改。

### JavaScript 单元测试

使用 Node 内置测试运行器覆盖：

- 链接协议分类与未知协议拦截。
- Windows/Unix 相对文件路径解析、URL 解码和标题片段拆分。
- 文件导航栈的压入、返回、去重和手动切换清空。
- 文件库排序、当前项判断和菜单可视区域定位计算。

### Rust 单元测试

覆盖：

- 从 `recent.json` 迁移到 `library.json`。
- 路径去重、登记、移出和持久化。
- 未登记路径、目录、缺失文件和不支持扩展名均被回收站命令拒绝。
- 回收站调用失败时不修改文件库或阅读进度。
- 回收站调用成功后才清理记录；测试通过注入临时回收站执行器验证，不移动用户真实文件。

### 构建与交互验证

- 运行 JavaScript 测试、Rust 测试、前端生产构建和 Rust/Tauri 编译检查。
- 使用桌面宽度与窄窗口验证侧栏互斥、文本截断、菜单边界和当前项高亮。
- 实际验证右键移出、取消删除、确认移入回收站、失效文件、外部网页链接、文档锚点、本地文档链接和返回滚动位置。
- 检查页面身份、非空渲染、框架错误层、控制台错误和关键交互后的 DOM/截图证据。
- 对重新生成的源图和主要派生图检查尺寸、透明角像素与视觉边缘。

## 验收标准

- 阅读时可展开文件目录，且与文章目录互斥。
- 已打开文件自动进入文件库，顺序和当前项状态正确。
- “移出文件目录”绝不触碰原文件。
- “移到回收站”始终先确认，失败不丢记录，成功后磁盘文件进入系统回收站。
- 网页链接不再替换 MD Reader 页面。
- 锚点留在当前文档；本地文档链接可打开并返回上一文件和滚动位置。
- 图标四角 alpha 为 0，内部图案无意外变化，小尺寸没有白色方角。
- 已确认的无用文件和代码被移除，README 与实际目录一致。
- 自动测试、生产构建和关键桌面交互验证均通过；未验证项在交付说明中明确列出。
